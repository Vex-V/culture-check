# Culture Check

Shows which age groups a video's cultural cues reach, using Qloo's taste graph.

Upload an ad of up to 90 seconds, or open an example report. The Real-world results tab
shows judged appeal next to the reach Meta publishes for ads shown in the EU.

Code and documentation: https://github.com/Vex-V/culture-check
